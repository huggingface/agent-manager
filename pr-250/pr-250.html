AGENT MANAGER - PR #250 - BUG FIX
ANTIGRAVITY: REPAIR ~/.GEMINI LINKS BEFORE LAUNCH, KEEP SQLITE OFF THE BUCKET, WARN WHEN THEY BREAK
AGY
1

INTRODUCTION.

agy keeps its SQLite conversations under ~/.gemini/antigravity-cli and ~/.gemini/config, which the entrypoint links to local disk once, at boot. From 20 Nov 2026 both were real directories on the bucket (/data); agy wrote SQLite onto hf-mount and four conversations came back malformed. This PR puts the links back before every agy launch, at server start and every 30 s, and warns while one is broken (figure 1).

2

HOW IT WORKS.

(1) state-links.js lstat's every CLI state link; when Antigravity's are fine that is all it costs. (2) runner.js calls it before each agy launch or resume; index.js at server start and every 30 s. (3) A broken link runs agent-state.sh relink-antigravity. (4) A real directory is merged into local disk, moved aside, never deleted, and linked again. (5) /api/info.stateLinks feeds the banner. (6) The suspected cause: hf-mount dropped the hand-repaired ~/.gemini/config link within minutes on 24 Nov; agy then mkdirs a real directory on the bucket.

2.1

Never under a running agy.

An agy process with this HOME, or any process with a file or cwd in the directory, defers the repair: nothing moves, the log says DEFERRED, and the next launch retries (figure 2).
